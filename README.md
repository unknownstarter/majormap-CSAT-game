# 수능 감독관 이야기: AI 안경을 부숴라

수능 감독관이 되어 AI 안경·단추 카메라·귓속 이어폰을 뿅망치로 부수는 45초 미니게임입니다.
게임이 끝나면 메이저맵 방어부적 페이지(https://www.majormap.net/saju/charm/1)로 이어집니다.

- 정적 사이트입니다. 빌드 과정이 없고 `index.html`과 `three.min.js`(three.js r128, MIT) 두 파일로 동작합니다.
- Vercel: 이 저장소를 가져온 뒤 Framework Preset을 "Other"로 두고 그대로 배포하면 됩니다.
- 모바일 세로 화면 기준으로 맞췄고, PC에서도 키보드·마우스로 플레이할 수 있습니다.
